# License of the replay data

`replay.json` contains text derived from the dialogues of SpokenWOZ: the induced structure of the SpokenWOZ domain
artifact (action names and typical user turns of each state) and conversations of the closed-loop simulation, whose
user goals come from the SpokenWOZ test set and whose system turns were produced by agents built from SpokenWOZ.
